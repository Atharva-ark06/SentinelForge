# Incident response workflow

1. Validate the alert and preserve the referenced event evidence.
2. Establish a UTC timeline and identify the affected account, source and host.
3. Correlate related authentication events and approved maintenance activity.
4. Escalate confirmed suspicious activity to the system owner.
5. Record decisions, containment actions and evidence references.
6. Close only after validation and document lessons learned.

This project is an educational tool, not an autonomous containment system.
