# Release checklist

- [ ] Review complete diff and dependency changes.
- [ ] Run backend tests and compile checks.
- [ ] Run frontend install and production build.
- [ ] Confirm workflows use least privilege.
- [ ] Check secret scanning and dependency alerts.
- [ ] Update version and release notes where appropriate.
- [ ] Verify deployment and rollback procedure.
- [ ] Confirm no real telemetry or credentials are included in fixtures.
